## 검증과 한계

- 새 Unity 테스트 assembly로 EditMode **119/119 통과**. 자동 병합으로 섞인 모델 검사 기준은 기존 리그 프리팹의 renderer bounds 검사와 원본 모델의 정점 검사로 분리했다. 허용값과 모델 크기는 바꾸지 않았다. 이 검사는 실제 신장이나 손의 시각 품질 합격을 뜻하지 않는다.
- 실제 입력으로 참호 끝 이동 → Tab → 전차 선회 종료 대기 → 바주카 두 발 → 격파·새벽 전환을 확인했다. 정면 실제 발사 도탄과 재시도 위치/방향 복구도 확인했다.
- 타이틀·튜토리얼 전차 숨김, 실제 튜토리얼 표적 조준 명중과 수동 R 장전을 확인했다. 조건 진입에는 디버그 이동을 사용했으며 자연스러운 9분 전체 시연 완주로 표현하지 않는다.
- 전방 경계는 여러 시작 지점과 대각선 이동으로 확인했다. 목재 끝의 바주카 사선과 근접 지면 연결을 실제 화면에서 검토했다.
- 파괴 화면의 청록 사각형은 GameView Gizmos를 끈 비교에서 사라졌다. 실제 VFX를 불필요하게 바꾸지 않았다.
- 이번 결과는 Unity 프로젝트 통합이다. 새 Windows 실행 파일 빌드나 손 전체 개선 완료를 주장하지 않는다.
