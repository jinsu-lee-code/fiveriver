# 다부동 맵 아트 이관

원본: https://github.com/alslxhrl7-web/blender-ai-game-assets-guide/tree/6614ff7d66660fa7ff0e3195f755ae89a638a678

`M01_Dabudong.unity`에서 지형, 참호, 마을·도로·엄폐물·식생 배치를 아트 프리팹으로 옮겼습니다.

- 프리팹: `five_river/Assets/_Project/Art/Maps/Dabudong/SM_ENV_Dabudong_Map.prefab`
- 재질·텍스처·모델·TerrainData: 같은 폴더의 `Source/`에 모았습니다. 에셋 GUID를 유지했습니다.
- 원본의 월드 좌표와 배치를 유지했습니다. 프리팹 위치 (0,0,0), 회전 (0,0,0), 크기 (1,1,1)로 확인합니다.
- 과거 맵의 실행 스크립트·마커·경로 표시, 카메라·조명·후처리는 맵 프리팹에서 제외했습니다.
- 현행 `Scenes/Dabudong.unity`, 게임 코드와 무기·캐릭터·오디오 에셋은 변경하지 않았습니다.

## 확인 결과

Unity 6000.6.0f1에서 원본 맵을 열고 프리팹을 저장했습니다. 오브젝트 586개, Renderer 569개, Terrain 1개, Collider 147개입니다.
스크립트·메시·재질·지형 레이어·나무 프리팹 누락 0건을 확인했습니다. 모델과 텍스처의 Git LFS 포인터가 아닌 실제 파일을 포함했습니다.
`map_overview.png`, `map_top.png`는 이관한 맵의 확인용 렌더입니다.

## 적용 범위

현재는 아트 납품 단계입니다. 현행 게임 씬에 배치하거나 기존 맵을 교체하지 않았습니다. 원본 맵과 현재 게임의 이동 경로·전차 경로·체크포인트 연결 및 실행 빌드 플레이 검증은 별도 통합 작업입니다.
원본은 Unity 6000.6 계열입니다. 검증은 설치된 6000.6.0f1에서 했으며, 프로젝트 기준 6000.3.25f1에서의 재검증은 하지 않았습니다. 프로젝트 엔진·패키지 설정은 변경하지 않았습니다.

기존 `art`의 병합 커밋 `9f28776`(아트·애니메이션·사운드·main 통합)에 맵만 추가했습니다.
파일별 해시는 `ASSET_MANIFEST.json`, 에셋 검사 수치는 `map_validation.json`에 있습니다.
