### 사용자 규칙
- 사용자에게 보이는 글은 전부 한국어(중간 설명, 작업 목록, 마무리 요약까지). 코드 · 경로 · 명령어만 영어.
- 커밋 · 푸시 · 빌드는 사용자가 그 요청에서 말했을 때만. 커밋은 작업별로, 메시지는 MM.DD/분야/PascalCase + 한국어 본문 + Co-Authored-By 줄.
- 기준은 "이상하면 안 된다". 숫자만 보지 말고 크게 찍어 눈으로 확인(선임 3D 애니메이터 기준). 문제를 찾으면 먼저 고치고 보고. 잘 된 부분은 건드리지 않는다.
- Unity는 한 번에 한 에이전트만. Blender는 백그라운드로만.
- 플레이 점검 스크립트는 멈추기 전에 Time.timeScale = 1 로 되돌린다. 끝나면 ProjectSettings/TimeManager.asset 이 m_TimeScale: 1 인지 확인.
- 씬에서 이름이 __ 로 시작하는 오브젝트(__PlayerBlockerWall 등)는 지우지 않는다. 임시 카메라는 씬에 저장하지 않는다.
- 임시 점검 도구(Scripts/DebugTools/Claude*.cs, Scripts/Editor/Claude*.cs)는 커밋하지 않는다. 씬은 바뀐 부분만 골라 커밋.
- 사용자 개인 정보는 외부 서비스에 보내지 않는다. 비밀번호는 사용자가 직접 넣는다.
