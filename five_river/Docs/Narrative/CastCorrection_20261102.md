# 등장인물 구성 정정 — 학도병은 새벽 보충 인원과 합류

2026-11-02 사용자 최신 정정을 우선한다. 사용자는 학도병을 삭제하라고 요청하지 않았다. 초반에는 등장하지 않고 새벽 보충 인원과 함께 합류하는 구성이다.

| 인물/역할 | 적용할 구성 |
| --- | --- |
| 오석구 | 플레이어인 신병. 학도병으로 해석하지 않는다. |
| 박용팔 | 기존 철모·군복 외형과 만수를 찾는 호출·역할을 유지한다. |
| 최만수 | 정적 구간의 부재와 마지막 이름·편지로 전달되는 동료 병사. 기존 설정 유지. |
| 초반 일반 아군 | 녹색 군복·군모의 정규군 모델. 학도병이 처음부터 참호에 등장하지 않게 한다. |
| 새벽 보충 인원 | 학도병의 합류를 유지한다. 기존 증원 수·시점·동선은 바꾸지 않는다. |

## 확인된 문제와 수정 범위

일반 아군과 새벽 증원이 같은 PF_CH_ROK_Soldier 프리팹을 공유해 학생병 외형이 초반부터 등장하고 있었다. 초반 모델 교체가 새벽 학도병까지 없애지 않도록 연결을 분리한다.

- ROK_Soldier/SK_CH_ROK_Soldier.fbx: 검은 교복·학생모, StudentSoldier_Rigged_Mesh. 새벽 합류용으로 보존한다.
- ROK_Protagonist/SK_CH_ROK_Protagonist.fbx: 녹색 군복·군모. 보정된 기존 예비 모델을 초반 일반 아군에 사용한다.
- ROK_ParkYongpal/SK_CH_ROK_ParkYongpal.fbx: 성인 병사의 철모·군복. 정상 모델을 보존한다.

PF_CH_ROK_Soldier의 Model과 CharacterImportSetup의 해당 매핑은 Protagonist 군복 모델로 변경한다. 초기 아군의 프리팹 GUID·등장 역할·배치·충돌체·무기·총구 참조는 유지하고, 새 Animator 참조와 몸체별 Idle/Call 접지만 맞춘다. 별도 학생 증원 프리팹은 교체 전 Soldier 모델을 사용하며 DawnDirector의 증원 참조를 여기에 연결한다. 기존 네 명의 증원 구성·경로·속도·연출 시점은 유지한다.

박용팔 원래 모델·전용 애니메이션, 맵, 튜토리얼, 기존 이야기와 R7 기능은 유지한다. 원본 기획 DOCX와 납품 모델은 수정하거나 삭제하지 않는다.

## 확인 과정의 정정

학도병을 완전히 제외한다는 초기 해석은 잘못됐으며 사용자의 최신 확인으로 폐기한다. 첨부 v1.2는 새벽 보충병 실루엣을 명시하고, 학도병 포함 여부는 사용자가 이번 대화에서 직접 확인했다.

RegularSoldier_20261102/model_comparison.png의 실제 화면 순서는 왼쪽 Park / 가운데 Protagonist / 오른쪽 Soldier이다. 초기 좌우 설명과 Park-only 판정은 잘못됐다. 임시 Park 교체는 원본 백업으로 되돌렸으며 최종 검증은 초반 인물과 새벽 학도병의 개별 플레이 이미지 및 mesh/avatar 경로로 진행한다.
