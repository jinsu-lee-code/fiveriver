### 5-2. 실제 적용 사례 (검증된 것만)
- **전체 흐름 연결**: 시작 화면 → 학습 → 정찰 → 주 공세 → 정적 → 전차 → 새벽 → 편지 → 시작 화면이 실행 빌드에서 이어짐. 자동 점검 모드로 **실행 빌드 3회 · 10회 연속 완주 통과**, 오류 0.
- **시간 상한 확인**: 디버그 창으로 시계를 옮겨 7:00 · 8:15 강제 전환과 9:00 종료(540초)를 확인. 회차 기록 CSV에 그대로 남음.
- **요청서 자동 검사**: 최종 FBX · 소리가 들어오면 파일명 · 부품 이름 · 크기 · 축 · 클립 · 소리 연결을 EditMode 테스트 71개가 자동 확인.
- **빠른 확인 도구**: F1 디버그 창으로 원하는 구간에 바로 들어가 확인 (측정 봇 대신).
- 시간 절감률은 측정하지 않았다.

## 6. 게임 실행 및 조작 안내 (현재 빌드 기준)

> 아래는 **10/27 그레이박스 빌드** 기준이다. 최종 제출 빌드(11/3)에서 다시 확인해야 한다.

- **실행 파일**: `FiveRivers.exe`
  - 시연용: `five_river/Builds/Windows/` (릴리스 빌드, 130.6MB, 디버그 창 없음)
  - 개발용: `five_river/Builds/WindowsDev/` (F1 디버그 창 있음)
  - 실행 폴더 전체를 복사해서 쓴다. 기본 1920×1080 전체 화면.
- **시작**: 시작 화면에서 **Enter** (또는 Space · 왼쪽 클릭)

| 키 | 행동 |
|---|---|
| W A S D · 마우스 | 이동 · 시점 |
| 왼쪽 클릭 / 오른쪽 클릭 | 사격 / 조준 |
| R | 장전 (M1은 8발을 다 쏘면 자동 장전) |
| F | 탄약 상자 옆에서 보충 |
| 1 / 2 | M1 개런드 / 바주카 (바주카는 전차 구간부터) |
| Z | 자세 낮추기 · 일어서기 |
| Shift | 달리기 |
| Esc | 일시정지 (회차 시간은 계속 흐름) |

- **종료**: 편지 · 제목이 끝나면 자동으로 시작 화면으로 돌아온다. 프로그램 종료는 Esc 일시정지 상태에서 **Alt + F4**.
- **운영자 재시작**: **Ctrl + Shift + R** — 어디서든 시작 화면으로 돌아가고 모든 상태를 초기화한다.
- **플레이 시간**: 설계상 약 7분, 최대 9분 (9분이 되면 어떤 상태든 결말을 거쳐 시작 화면으로 돌아감).
  - 확인된 것: 시계를 강제로 옮긴 시험 회차가 540초(9:00)에 정확히 끝남.
  - **사람이 처음부터 직접 플레이한 시간은 아직 측정하지 않았다** (관찰 테스트 3-1 예정).
