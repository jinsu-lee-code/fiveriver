19개 합격 원본에서 만든 별도 규격 복사본. WAV 48kHz PCM16, SFX 모노 / AMB 두 채널, true peak <= -1dB.
원본 길이·속도·피치를 유지. 모노 환경음은 듀얼 모노이며 공간 스테레오 복원이 아님.
파일명 및 길이가 SOUND_LIST 전체와 일치하는 완성 세트는 아님. 별도 변형·목록 매핑 검토 필요.
게임 연결과 .meta를 포함하지 않음. 자동 설치하지 말고 별도 검수 후 사용.
원본 합격은 승계했지만 채널 변환의 청감은 청취판에서 비교 가능. 출처별 조건과 미확인 사항은 Manifest.json 참조.
